# 📊 Spend Analytics Dashboard (Tableau)

An interactive **Spend Analytics Dashboard** built using Tableau Public to analyze procurement data from **2017 to 2020**.

This project focuses on understanding vendor activity, spend distribution, and procurement trends through a clean and executive-friendly dashboard design.

---

## 🚀 Project Overview

Organizations often struggle to monitor spending patterns, vendor concentration, and category-level expenses.  
This dashboard transforms raw procurement data into actionable insights by highlighting:

- Active vendors per year
- Year-over-year vendor trends
- Category-wise spend distribution
- Vendor location insights
- Procurement pattern shifts over time

The goal was to build a structured, insight-driven dashboard rather than just a collection of charts.
